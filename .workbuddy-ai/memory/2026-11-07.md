## 等待态设计（`components/DraftItem.vue`）

不优化速度，只处理「空」：`.btn:disabled` 的 40% 透明会把几颗按钮一起压成灰条。

- 文案进行时：发送→发送中、记下→记录中、保存名字→保存中（`WAIT_LABEL`）
- 主按钮 `.is-waiting:disabled { opacity: 1 }` + 窄光带 `::after` 横扫（1500ms linear）
- 卡片 `.is-sending` 外圈 2.4s 呼吸（`box-shadow` 0→3px），次要按钮压到 0.26
- 2.5 秒后 `SLOW_NOTE[type]` + 一直在涨的秒数（`role="status"`，秒数 `aria-hidden`）
- 文案按类型分开：只有 REPLY/FILE 真去找 QQ，MEMO/FACT/NAMING 只是写库

两个坑（已写进 Vue README）：

1. **主按钮要定 `min-width: 104px`**，否则「发送」→「发送中」按钮自己长胖，把旁边的按钮推着走。
2. **扫光只能逐个点名 `.btn-label / .spinner / svg`，不能写 `> *`**。按压波纹的 `.ripple-ink`
   也是直接子元素，靠 `position: absolute` 才不占位；被改成 `relative` 后变成 160×160 的
   flex item，按钮直接从 96px 被撑到 256px（实测）。文字是裸文本节点选不中，所以外面包了 `.btn-label`。

## 「模型擅自替用户回答」的排查与修复

用户先问原因，随后贴日志 + 草稿中心截图圈出**空草稿**问题。结论：不是单点，是四层叠加。

### 为什么「越来越」敢答（根因，尚未修）

`ChatSettingServiceImpl.recentMessages()` 把 `message_log` 里 `direction=OUT` 的行也塞进
上下文，而 OUT 行是**插件自己发出去的那句话**（`default.py` 的 `log_queue.enqueue`，`content: sent`）。
于是模型每擅自答一次，这句话就变成下一轮的「主人说过的话」，形成自我强化。
**这是「越用越敢答」的真正来源，改提示词治不了。** 建议过滤 OUT 或只留最近 2 条。

另外 `chat_decision` 的 `temperature: 0.7` 对分类任务太高，建议 0.1。

### 提示词的结构性漏洞（已修）

1. 规则第 1 条就是「普通聊天 → SEND」，整篇基调定在「回复」上。
2. **硬性约束被限定在「闲聊（CHAT）时」生效**——模型判成 `TASK` 就整段绕过，
   而 `TASK` 恰恰是「永远发得出去」的那一类：约束和门控同时失效。
3. `needs_confirm` 靠枚举（承诺/钱/时间/见面/表态），枚举外一律 SEND。
4. 8 个 few-shot 全是「怎么把事办好」，没有一条「别人在问主人，应该闭嘴或出草稿」。

新版提示词：先立身份（影子 ≠ 主人）→ 三道闸（要主人的真实情况吗 / 是别人在问主人吗 /
材料里真有答案吗）→ 拿不准一律 DRAFT 或 SILENT。硬性约束改成「所有输出都适用」。

### 空草稿这条 bug 的四层修复

用户圈的是：草稿卡上「对方 · 小号 回复：是否忘记带书」+ 正文「回复：是否忘记带书」，
同一句出现两遍，且正文是空的。

| 层 | 问题 | 修法 |
|---|---|---|
| 提示词 | 曾允许 `payload.content` 留空、`title` 写「回复：xxx」 | 新增「DRAFT 怎么写」：title 一律留空、content 必填且能直接发；拿不准就写一句**拖住**的话（「我看看，晚点回你」） |
| 插件 | `dispatch.py` 的 DRAFT 分支**没带** `sourceContent/sourceSenderName/sourceChatName`（`needs_confirm` 那条路一直带着） | 抽出 `reply_draft_source()`，两条路共用；`handle()` 新增 `source` 参数 |
| 后端 | `dispatchReply` 直接发 `payload.content`，**无空值校验** → 空草稿点发送会发空消息还标 CONFIRMED | `requireReplyContent()` 在**状态变更之前**拦（不靠事务回滚兜底），`dispatchReply` 再兜一次 |
| 前端 | `headline` 在 content 空时回退 title，`context` 也回退 title → 同一句两遍 | `context` 只认 `sourceContent`（不知道就说不知道，不编）；空正文显示斜体占位「这条还没写内容」并禁用发送 |
