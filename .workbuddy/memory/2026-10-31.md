# 2026-10-31

## 第八轮：首页页头「干瘪」+ 下拉刷新补齐

用户圈了首页页头（日期 / 你不在的时候 / 副标题），说只有文字太干瘪；另外说下拉刷新没加上。

### 1. 页头加结构（`HomeView`）
- 日期做成**深色胶囊**（`--card-inverse` + 白字 + 6px 粉色小点，点外面一圈 3px 柔光），
  在冷灰画布上给页头一个「日期戳」式的锚点，不靠加装饰图。
- 右侧加一个 30px 白色圆形刷新按钮（`RefreshCw`），加载时图标自转、按钮禁用。
  一左一右两个形状把原来三行纯文字的块撑起来，同时把「能刷新」这件事显式化。
- 这个日期胶囊塞在 `.eyebrow` 里（`.eyebrow.head-row`），这样滚动收起时能复用全局
  `.app[data-scrolled="true"] .page-head .eyebrow { opacity:0; max-height:0 }` 的收起逻辑。
- 只改了首页：其它页的 eyebrow 是「草稿中心 / 历史查询」这类标签，文字本身没问题。

### 2. 下拉刷新（`AppShell`）——原来其实有，但触摸端是坏的
- **根因**：只监听了 pointer 事件。触摸设备一旦开始滚动，浏览器会 `pointercancel`，
  后面就没有 `pointermove` 了，等于完全拉不动。桌面用鼠标拖是能用的，所以「看起来没做」。
- 改成两条路：鼠标走 pointer（并 `setPointerCapture` 保证拖出元素也能收到 up），
  触摸走 `touchstart/touchmove/touchend`，`touchmove` 用 `{ passive: false }` 注册，
  下拉方向明确时 `preventDefault()` 接管手势；横向滑动/上推则让给浏览器滚动。
- 观感也重做了：原来是固定的小圆点从顶部滑出（大部分时间藏在页头后面，几乎看不见）。
  现在**内容整体跟着手指下移**（`.screen` transform + 松手 spring 回弹），
  指示器落在顶部露出来的那道缝里，`pull/2` 居中；`body.pulling` 时禁掉文字选中。
- 阈值 56px，阻尼 0.55；松手未过阈值直接回弹。
- `MoreView` 原来没注册 `useRefresh`，补上了（顺手把 `loading=true` 从 `load()` 里去掉，
  否则下拉时概览数字会闪一下「—」）。`AskView` 不注册——对话页没有可刷新的东西。

### 3. 顺带修掉的一个真 bug
首页页头变高后，在小视口（内容只比视口高几十 px）出现「刚滚就弹回顶部」：
收起页头会让内容整体上移，浏览器把 scrollTop 夹到 0，又跨过展开阈值 → 展开 → 再收起。
改成**先估算收缩量再决定要不要收**：`shrink = 页头实际高度 - 44`，
只有 `可滚距离 > shrink + 2` 时才收起。长页面照常收，短页面干脆不收（也不会被页头盖住太多）。

### 验证
- 鼠标拖拽 130px：`transform: translateY(71.5px)`、指示器 opacity 1、松手后 `GET /api/digest` 发出 2 个请求；
  触摸事件（`Input.dispatchTouchEvent`）同样通过。
- 10 页 × 8 个滚动位置：`flips` / `spread` 全 0，页头抖动没有回归；`/memos` 滚 160px 仍能收起到 40px。
- 11 条路由控制台 0 报错；`vue-tsc -b --force` + build 通过。

## 第九轮：页头重做成统一组件（大标题 + 光晕 + 折叠）

用户给三张参考稿（Health Karma / Convora / to-do）让「重新优化页头的表现」。上一轮给首页加的
「日期深胶囊 + 刷新圆钮」已不在代码里，这轮改为**以排版为主**的方案，不再加装饰性控件。

### 1. 新增 `src/components/PageHead.vue`
页头是全站唯一被 11 个页面重复画的东西，且同时承担「页面身份」和「滚动后收起的粘性条」两种形态，
散在各页各写一遍字号迟早走样。收成组件，props：`title` / `eyebrow` / `sub` / `back`，
`#actions` 插槽放右侧动作（目前只有拦截规则页的新建按钮用）。

结构：返回药丸 → 小标签 → 标题（+ 右侧动作，同一行）→ 说明。
- 动作与标题同一行且 `align-items: flex-start` + `margin-top: 6px`：对齐的是标题「字面顶」，
  标题换成两行时按钮不会飘到两行中间。
- 返回做成 30px 药丸（`rgba(17,18,20,.055)`），比一行纯文字明确可点，又比大箭头安静。

### 2. 排版与底色（`style.css`）
- 标题 36 → **40px**，行高 1.04 → 1.02，`text-wrap: balance`；`@media (max-width:380px)` 退到 34px（360dp 安卓机）。
- **字距只收 -0.03em**：一开始照拉丁稿收到 -0.045em，「记忆」「拦截」这类左右结构的字会互相顶到，
  截图对比后回调。中文字形撑满字身，-0.05 那套不能直接搬。
- 小标签前的 14×2 强调色短线换成 **4.5px 圆点 + 2.5px 柔光**，字距 0.12em → 0.14em。
- 页头底色从「一层白光」加厚成**两层**：左上暖白 + 右上一点 `rgba(229,56,127,.085)` 余晖，
  再沉到画布色。参考稿那种「有光打下来」的感觉靠这层，不是靠投影。
- 间距：小标签→标题 14px；标题→说明 15px（40px 标题行高 1.02，字框下几乎没余白，
  写 12 视觉上像贴着标题）。说明 13.5 → 14px。
- 收起态：标题 17px、`padding` 12/12、发丝线；**返回行也一起收掉**（`max-height:30px→0`）。
  返回留着会把窄条撑成两行；目标平台是 Android，系统返回手势始终在，取舍可接受。

### 验证
- 390dp：`/home` 149px、`/memos` 112px、`/memory` 215px 页头高；11 条路由逐页截图比对，
  标题、小标签、说明的基线与留白一致。
- 360dp：标题落到 34px，「你不在的时候」仍单行不顶边；412dp 保持 40px。
- 收起态（`/memory` 滚 520px，`data-scrolled=true`）：窄条只剩 17px 标题 + 发丝线。
- `npm run build`（vue-tsc -b + vite build）通过；临时截图脚本与 shots/ 已清理。

## 第十轮：页头再做一版（用户说「几乎没什么变化」）

上一轮只调了字号和间距，视觉上没跳出来。这轮动的是**结构**，目标是「刊头（masthead）」而不是「标题块」。

### 1. 小标签 → 半透明白胶囊
- 从「圆点 + 灰字」变成一枚 28px 高的玻璃胶囊：`rgba(255,255,255,.72)` + 1px `rgba(17,18,20,.07)` 描边 +
  极浅投影。用白而不是灰，是因为它压在暖色光晕上，白底会把下面那层光「托」出来，像浮着的玻璃而不是贴着的灰条。
- 圆点保留，外面 2.5px 粉光圈。

### 2. 标题 40 → 46px，行高 1.02 → 0.98，字距 -0.03 → -0.035em
中文没有下伸部，行高压到 0.98 不会切字，只会让标题块更「实」。
`@media (max-width:380px)` 退到 38px（360dp 实测「你不在的时候」仍单行）。

### 3. 返回：文字药丸 → 白色圆钮
36px 白圆 + `--shadow-card`，和右侧动作钮、胶囊标签凑成同一套「小圆角块」语言。
`aria-label` / `title` 用 `back.label`（原来那行「更多」文字的信息没丢）。

### 4. 底色：三层光
右上 `rgba(229,56,127,.13)` 余晖 → 左上 `#fff` 暖白 → `#fcfbf9 / #f4f3f1 / var(--bg)` 渐变。
顶部 padding 16 → 20，说明离标题 14 → 18（46px 标题的说明，光学间距要到字号的四成才不黏）。

### 5. 试过又删掉的两个东西（重要，别再加回来）
- **右上角圆弧装饰**：标题一长（「你不在的时候」）就被弧穿过，且弧在页头底边被 `overflow:hidden` 硬切断，
  看着像渲染错误。装饰一旦和内容打架就是噪音。
- **底边内阴影**（`inset 0 -22px 26px -26px rgba(...,.18)`）：想做「纸的厚度」，实际渲染成一条脏灰带，
  比平滑渐变难看。去掉后页头和内容之间是干净的软过渡。

### 6. 备忘页：搜索框与分段控件拉开
`.seg` 原来紧贴搜索框（0 间距），两枚灰药丸叠在一起像同一块控件坏了。
加了 `.search + .seg, .search-count + .seg { margin-top: 16px }`；搜索框 38 → 42px，`padding` 0 12 → 0 14。

### 验证

## 第十三轮：v3 设计系统「纸与墨」（整体视觉重做）

用户「开放你的思维，大胆设计，让前端页面变得更加高级有艺术感」。
上一版是冷灰 + 纯白圆角卡 + 柔阴影，干净但通用：卡与卡之间只有间距差别，字号一拉平就是一串同质方块。
这一轮换的是**材质与排版**，不是配色倾向。全部改动集中在 `style.css` 的设计 token + 组件/视图的局部样式。

### 1. 调色板：冷灰 → 暖纸
- `--bg #ededed → #f4f1ec`、`--card #ffffff → #fffdfa`、`--surface #efece5`、
  `--hairline #e5e0d6`、新增 `--rule #dcd6c9`。
- 全文把 `rgba(17,18,20,x)` 批量换成 `rgba(46,38,26,x)`（冷灰阴影在暖底上发青）。
  `index.html` 的 `theme-color` 同步 `#F4F1EC`。
- 阴影从三层减到两层，去掉 1px 描边环（改由真实 `border` 承担）。
- **强调色分两支**：`--accent #d92e73` 只做「面」（圆点/角标/色块，4.06:1 够用）；
  新增 `--accent-ink #c92668` 给「字」（时间、@你、逾期数字），4.71:1 过 AA。

### 2. 排版：衬线 + 微标签
- 新增 `--font-display`：`Georgia → Times → Noto Serif → 宋体`。
  只给英文标题、抽屉标题、大数字、时间列。**中文正文永远不用衬线**（15px 宋体会糊）。
- `.page-title` 保持 32px 但改成衬线 400 字重——同样字号下视觉重量轻一档，却更有存在感。
  这是对用户两次「标题太大」的正确回应：不是继续缩字号，是换字体。
- 新增 `.label`（10px / 0.18em 大写）与 `.display-num`（衬线数字）。

### 3. 栏目线：分节标题全站收敛成一套
原来每个页面各写一套（备忘 12px 灰字、设置 17px 粗黑、更多 11.5px）。
现在 `style.css` 里一条规则同时管 `.section-title / .block-title / .group-title / .group-label`：
`display:flex` + 微标签 + `::after` 撑满引导线（`order:1`）+ `.num` 衬线数字（`order:2`）。
**用 flex + order 是为了不改各页模板**——标签是文本节点，天然 order 0。
各视图只保留 `margin-bottom` / `sticky` 这类局部差异。

### 4. 结构
- **页头**：`.eyebrow` 从圆角药丸改成方形「印章」（6px 圆角 + 发丝线 + 4px 强调色方块）；
  `PageHead` 里加 `.head-rule` 引导线，把第一行连成一条版式。
- **卡片**：1px 发丝线压边 + 几乎不投影（印刷品贴在纸上，不浮在空中）。
  深色面统一 `linear-gradient(158deg,#221f26,#16151a,#121116)` + `inset 0 1px 0 rgba(255,255,255,.07)`。
- **底部导航**：从贴边白条改成浮起的「书签条」（左右 10px、底部 8px、20px 圆角、发丝线）。
  `.screen` 的 padding-bottom 与 `.fab` 的 bottom 跟着 +10px。
- **FAB 从圆变方**（`--r-md`），和印章语言一致。
- **按钮从药丸变章**（`--r-sm` 10px）：满页方角卡片里再放一颗糖果会打架。
  `.btn-quiet` 从灰底改成发丝线描边（灰底在纸上看像被禁用）。
- **更多页的深色统计块**（0/1/0）换成「年报数字栏」：上下发丝线 + 三列 + 34px 衬线数字，左对齐。
  原来那块黑圆角矩形是仪表盘插件的形状语言，和纸感脱节，而且是整页最响的一块。
- **空状态**：灰底圆形气泡 → 30px 发丝线圈；标题改 21px 衬线（空屏唯一能撑住版面的就是这行字）。
- **抽屉**：内部纯白信息板 → 5.5% 白半透明板 + 发丝线（黑底上突然一块 100% 白太刺眼）。
- **纸纹**：`feTurbulence` 生成的 data-URI，`.app::after` 铺满整屏，5.5% 不透明度，`pointer-events:none`。
  刻意不跟内容滚——纸不动，动的是纸上的东西。

### 5. 踩到的坑
- **`.rule` 工具类撞名**：我给全局加了个 `.rule { height:1px }` 的引导线工具类，
  结果拦截规则页的卡片本来就叫 `.rule`，卡片被压成 1px 高、内容溢出。已删除该工具类，
  引导线一律用各分节标题的 `::after`。
- `.section-title` 在 style.css 里同时存在旧的 16px 版本和新的栏目线版本，旧的要删干净，
  否则同权重靠源码顺序决胜负，很难查。
- 单条备忘的分组不画脊柱：线藏在 21px 圆点背后，只露出上下两截小短杠，像渲染残留。
  用 `.timeline:has(> li + li)::before` 控制。
- `群列表` 右侧的 `1/1 已开启整理` 用了 `.num` + `.faint`，13px 比 10.5px 的标签还大；
  改成 `.num` 并在视图里覆盖回微标签字号。

## 第十六轮 · 自定义时间重做

原生 `<input type="datetime-local">` 在纸面表单里格外扎眼：UA 渲染的 `2026/10/31 15:00`
（斜杠 + 等宽空格）、右端一枚纯黑系统日历图标——全站唯一的纯黑图形。

### 做法：透明原生控件 + 自排一层
- `.time-native` 铺满整行、`color: transparent`（`::-webkit-datetime-edit` 也透明），
  `::-webkit-calendar-picker-indicator` 拉到 `inset:0 / 100% / opacity:0`，
  于是**点行内任意位置**都弹系统选择器（桌面端也能开日历）。命中测试三处都是 `time-native`。
- 上面盖一层自己的排版：`今天 · 16:00`——日期衬线 16px，星期/相对日微标签，
  时间衬线 15px 等宽数字，右端 lucide `CalendarClock` 15px。
- 今天/明天/后天用相对词，其余走 `formatHeadDate()` 拆成「11月4日」+「周三」。
- 下方提示从「10月31日 15:00 截止」（和上一行重复）改成 `relativeUntil()` 的「还有 1 小时 8 分」。
- 默认值顺手修了：原来 `now+1h` 再 `setMinutes(0)` 会落到「还有 10 分钟」这种怪值，
  改成「一小时后向上取整点」。

## 第十七轮 · 自绘日期时间选择器

- 用 `Sheet`（`nested` 叠加），标题「选择时间」，副标题实时显示 `10月31日 周六 · 17:00`。
- 月历：`‹ 2026年10月 ›`（衬线 17px，箭头 30px 发丝圆），周一开头的 6×7 格，
  邻月日子淡出，今天在数字下点一个 3px 品红点，选中落墨块（`--card-inverse`）。
- 时刻：两个 `scroll-snap-type: y mandatory` 滚轮（小时 24 格、分钟 12 格 ×5min），
  格高 44px、可视 132px、上下各留 44px 空档让首尾也能居中；
  选中带是两条发丝线，左右各缩进 18px 贴着两列数字。

### `Sheet` 加了 `nested`
