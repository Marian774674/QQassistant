# 2026-10-29

## 值守台前端 · 移动端重设计（QQMessageAssistantVue）

**背景**：用户要求参考一张三屏手机设计图（冷白灰画布 + 白卡 + 近黑强调卡 + 深色底部抽屉 + 无衬线字），
把原来「值日表」桌面管理台改成**移动端优先、简约现代高级**的界面。我的职责锁定前端设计，
`QQMessageAssistantJava` / `QQMessageAssistantPython` 只读不改。

**做了什么**

1. 重写 `src/style.css`：新 token（`--bg #EDEDED` / `--card #FFF` / `--card-inverse #101011` /
   `--ink #111214` / `--hairline` / `--r-lg 18` / `--r-sheet 28` / `--shadow-card`），删掉纸纹与衬线字体。
   `#app` 变成 430px 手机画布，宽屏居中成圆角设备框。
2. 新基础组件：`Sheet.vue`（底部抽屉，深色，Teleport 到 `#app`，替换旧 Modal）、`Segmented.vue`、
   `Skeleton.vue`、`DraftBanner.vue`（替换 DraftTray）。
3. 重排全部旧页：MemosView（勾选圆点 + 虚线时间轴 + 深色「接下来这一件」+ FAB）、DraftsView、
   MemoryView（事实列表 + 画像卡 + 总结频率）、SettingsView（改成卡片行，QQ 号可编辑）。
4. 新增三页补上后端空白：FilesView（`/api/file-tasks`）、LogsView（`/api/message-logs`）、
   RulesView（`/api/intercept-rules` CRUD + 正则命中测试），加 MoreView 做二级入口。
   路由 4 → 8 条，底部导航 4 tab（备忘/草稿/记忆/更多）。
5. 新增 `api/{files,logs,rules}.ts`、`utils/meta.ts`（状态/类型/图标映射）、
   `composables/{useFab,useDraftStore}.ts`（共享草稿缓存，解决重复请求）。
6. 删除 `Modal.vue`、`DraftTray.vue`。`npm run build` 通过。

**关键约定（后续改动请遵守）**

- 视觉语言：浅色为主 + 单张深色强调卡 + 深色底部抽屉；强调色 `#E5387F` 面积 <2%。
- 移动端硬性要求：390 基准、44px 触控目标、`env(safe-area-inset-*)`、无 hover 依赖。
- 详情/编辑一律用 `Sheet`，不要再用居中弹窗。
- 零依赖：不引入 UI 库 / Tailwind / pinia / axios。

**验证方式**：本地起了 mock 后端（`Temp/qq-mock.mjs`，8099）让 Vite 代理过去，
再用 headless Chrome + CDP（`Emulation.setDeviceMetricsOverride` 390×844@2x）截图核对。
注意：`chrome --headless --window-size=390` 会被钳到最小 500px，必须走 CDP 才能得到真实手机视口。
截图已归档到 `QQMessageAssistantVue/design/preview/`（12 张）。
