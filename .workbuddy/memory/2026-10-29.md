`QQMessageAssistantJava` / `QQMessageAssistantPython` 只读不改。

**做了什么**

1. 重写 `src/style.css`：新 token（`--bg #EDEDED` / `--card #FFF` / `--card-inverse #101011` /
   `--ink #111214` / `--hairline` / `--r-lg 18` / `--r-sheet 28` / `--shadow-card`），删掉纸纹与衬线字体。
   `#app` 变成 430px 手机画布，宽屏居中成圆角设备框。
2. 新基础组件：`Sheet.vue`（底部抽屉，深色，Teleport 到 `#app`，替换旧 Modal）、`Segmented.vue`、
   `Skeleton.vue`、`DraftBanner.vue`（替换 DraftTray）。
3. 重排全部旧页：MemosView（勾选圆点 + 虚线时间轴 + 深色「接下来这一件」+ FAB）、DraftsView、
   MemoryView（事实列表 + 画像卡 + 总结频率）、SettingsView（改成卡片行，QQ 号可编辑）。

   路由 4 → 8 条，底部导航 4 tab（备忘/草稿/记忆/更多）。
5. 新增 `api/{files,logs,rules}.ts`、`utils/meta.ts`（状态/类型/图标映射）、
   `composables/{useFab,useDraftStore}.ts`（共享草稿缓存，解决重复请求）。
6. 删除 `Modal.vue`、`DraftTray.vue`。`npm run build` 通过。

## 第二轮：动效与体验优化（同日）

用户反馈「还能再丝滑一点」，拍板：**要回弹**、撤销功能不急（不改后端）、下拉刷新要做、View Transitions 可以冲。

**改了什么**

1. 动效 token：`--dur-1/2/3 = 120/200/320ms`、`--ease-out`、`--ease-spring`。
2. 切页：`<Transition mode="out-in">` 保留但 leave 时长归零（`transition: none`），
   消灭中间空白；方向感靠 `route.meta.depth`（0 = tab，1 = 二级页）写进 `.screen[data-nav]`。
3. `Segmented` 与底部 tab 改成**滑动指示器**：纯 CSS，`--seg-n` + `translateX(index*100%)`，
   tab 用 `calc((100% - 20px)/4)` 的一格容器里放 40px 药丸。
4. 列表 FLIP：`TransitionGroup` + `.list-move/.list-leave-active`（leave 用 absolute 脱离文档流）。
5. 完成备忘改**乐观更新** + 失败回滚，勾选圆点用 `stroke-dashoffset` 画出来，`navigator.vibrate(6)`。
6. `Sheet` 加**下拉关闭**（pointer 事件、120px 或 0.55px/ms 阈值、scrim 联动）、
   `visualViewport` 键盘避让、`inert` 锁背景。
7. 页头**吸顶收起**（`.app[data-scrolled]`，阈值 12px，标题 30→18px，eyebrow/sub 收起）。
   ⚠️ 阈值一开始写 40px，但备忘页内容只够滚 31px，导致永远不收起、深色条幅从透明页头下透出来——这个坑要记住。
8. 分组标题 `position: sticky; top: 44px`；下拉刷新（AppShell 统一手势 + `useRefresh` 注册）；
   按路由记忆 `scrollTop`。
9. 统一 `ErrorState`，删掉 5 个页面里重复的 `.notice`；`Skeleton` 支持 `variant="timeline|card|log"`；
   表单校验失败抖动并聚焦；保存按钮内联 spinner。
10. View Transitions：备忘卡 → 抽屉共享元素（`memo-morph`）。
    关键点：**旧快照要有名字、新快照只能有一个同名元素**，所以先把名字挂到卡片上 → `nextTick` →
    `startViewTransition(async () => { 清卡片名; 开抽屉; await nextTick() })`；
    抽屉用 `:instant` 跳过自己的进出场，否则新快照拍到的是 translateY(100%) 的起始位置。

**顺手清掉的两件旧待办**（用户已批准）：
- `design/requirements.md` 附录 A 的 Vue 行改成「✅ 8 页」，日期更到 10-29。
- 删掉 `QQMessageAssistantVue/design/` 下与根 `design/` 重复的 9 个文档（只保留 `preview/`），
  Vue README 加了一行指向 `../design/`。

## 第三轮：调慢 + 切页改淡入淡出

用户反馈「动效快了一点」且切页要**淡入淡出**（不要位移方向感）。

- 时长整体放大约 1.4 倍：`--dur 220`、`--dur-1 160`、`--dur-2 260`、`--dur-3 400`；
  勾选描边 340ms、抽屉退场 300ms、toast 300ms、下拉指示器 320ms。
- 切页改成 `mode="out-in"` + 纯 opacity：淡出 160ms → 淡入 280ms。
  **代价**：out-in 在交接处会露出约一帧纯背景（实测 90ms 处整屏空）。
  若以后嫌这个"闪"，正解是去掉 out-in 让两页叠加做真交叉淡入，但离开页要 `position:absolute`，
  且得先解决滚动位置归零导致旧页跳到顶部的问题——当时评估不划算，没做。
- 顺手删掉 `navDir` / `router.beforeEach` / 路由 `meta.depth`（方向感不再需要，避免留死代码）。
