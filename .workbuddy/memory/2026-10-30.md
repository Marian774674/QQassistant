## 第五轮：把上一轮列出的 UI 改进建议全部落地

用户「上面提到改进建议的都可以采纳，动手吧」。这轮改 14 个文件，全部通过 `vue-tsc -b --force` 与 `npm run build`。

### 1. 误触可撤销（备忘完成改成延迟提交）
- 后端 `PATCH /api/memos/{id}` 只认 `DONE | CANCELLED`（`MemoServiceImpl.PATCH_STATUSES`），
  真正的「重开」要改枚举，用户说「不急」，所以换成**延迟提交**换撤销窗口：
  `MemosView.complete()` 先本地置 DONE + `toast.action(...5s)`，5 秒后才 `patchMemo`。
- `pendingDone: Map<id,{timer, original}>`；`undoDone` 清定时器 + 按 id 回滚单条（不整表快照，
  避免同时勾两条时互相覆盖）；`flushDone()` 在 `load()` 前和 `onBeforeUnmount` 时立刻落地，防止刷新/切页丢失。
- `useToast` 加 `ToastAction`（label + run），`ToastHost` 渲染行内按钮。最多同时 3 条。

### 2. 时间快捷块（替掉 datetime-local）
`MemoEditor`：今晚 20:00（过了 20 点自动变「明晚」）/ 明早 09:00 / 明天 18:00 / 下周一 09:00 /
自定义（展开原生输入）/ 不设时间。`toDatetimeLocalValue` 支持直接传 `Date`。

### 3. 列表信息修正
- `MemoRow` 新增 `now` prop（父级 30s 心跳传时间戳）+ `grouped`：
  - 跨天日期挪进时间块上方（「10月29日 / 15:30」），**同时删掉 `showDate` prop**，避免日期在 meta 和时间块重复两次；
  - 分组列表传 `grouped`，组标题已有日期就不再重复；
  - 逾期用 `inset 3px 0 0 var(--danger)` 左侧红边 + 时间转红，且按时间判断而非只信 `status === 'OVERDUE'`。
- 备忘页加**本地搜索**（标题/正文/分类），带结果计数与清空；空态文案按是否在搜索分流。
- 「现在」这条分隔线改成 `v-if="todayMemos.length"`，空列表不再孤零零一条线。

### 4. 草稿确认（不可逆动作）
`DraftItem`：REPLY / FILE 第一次点「发送」变成粉色确认条「会以你的身份发出，发出后无法撤回」，
6 秒不点自动收起；MEMO / FACT 仍是一步。

### 5. 可读性
- `--ink-3` 从 `#9a9ba0`（约 2.5:1）改到 `#696a6f`（约 4.6:1），`--ink-2` 同步压到 `#4b4c51`（7.3:1）；
  深色面 `--on-dark-2/3` 提到 0.72 / 0.48。小字元信息终于过 AA。
- 重要性五档改成「数字 + 文字标签」两行，比只有 1–5 好对。
- 记忆页画像 textarea 自动长高（`scrollHeight`，上限 420px）。
- 文件任务详情把 JSON 拆成中文键值行（`fills→已填写`、`confidence→78%`、布尔→是/否），原始 JSON 收进 `<details>`。

### 6. 性能与观感
- `Skeleton` 延迟 150ms 再淡入，快请求不再闪一下骨架。
- `main.ts` 用 `requestIdleCallback`（fallback 1.2s）预取其余 7 个路由 chunk。
- 「更多」页顶部加深色概览卡：今天要做 / 已逾期 / 待确认 + 「数据更新于 HH:mm」，三个数字可点进对应页。
- 文件任务、消息日志的空态补了下一步动作（看日志 / 重新读取）。
