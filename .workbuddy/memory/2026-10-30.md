## 第六轮：修「滚动时页头一直抖」

现象：任何有页头的页面往下滚一小段，页头（返回链接 + 大标题 + 副标题那块）持续抖动，内容从标题后面透出来。

### 根因（实测出来的，不是猜的）
`.screen` 里 `data-scrolled` 由 `scrollTop > 12` 决定；置 true 后页头高度从 147px 收到 70px。
**Chrome 的滚动锚定**为了「保持视野不动」，会在高度变化的每一帧补偿 `scrollTop`：
40 → 30 → 2 → 29 → 1……补偿后的值掉回阈值以下 → 状态翻回 false → 页头展开 → 锚定又把 scrollTop 推回去 → 无限循环。

用 CDP 采样验证：`top=40` 停住不动，1.2 秒内 `data-scrolled` 翻了 **15 次**，scrollTop 在 1–30 之间来回。

### 修法（三处，都在全局层）
1. `.screen { overflow-anchor: none }` —— 关掉滚动锚定，高度变化只发生一次。这是主因修复。
2. `.page-head { background: var(--bg) }` —— 原来非滚动态是 `transparent`，抖动时正好处于「透明态 + 内容已在下面」，所以文字透出来像重影。改成常驻画布色，顺便去掉 `backdrop-filter`（不透明背景上没意义，移动端滚动还很吃 GPU）。
3. 收起/展开改用**两个阈值**（`COLLAPSE_AT 28` / `EXPAND_AT 8`），挡住 iOS 顶部橡皮筋和手指微抖在阈值上反复穿越。

### 验证
- 逐页（/ /memos /drafts /memory /more /chat-settings /settings /files /logs /rules）× 8 个 scrollTop 档位，各停 0.6s 采样：`flips` 全为 0、`spread` 全为 0。
- 真实滚轮事件滚 1000px：scrollTop 单调、无回退。
- 430px 桌面画布下截图确认收起态干净。
